#Product-Responsive-Gallery

This repository contains HTML, CSS, and JavaScript code for a Responsive Product Gallery Website.

The project is a responsive web application built using core web technologies. It demonstrates responsive layout design, dynamic DOM manipulation, and modal popup functionality without using any external libraries or frameworks.

The Product Gallery folder includes all the source code files related to HTML, CSS, and JavaScript.

The folder structure is provided below for better understanding of the project organization.

The Description section helps users review the code screenshots in one place and understand the overall project workflow.

The Screenshots section contains images of the website displayed in both desktop and mobile views.
